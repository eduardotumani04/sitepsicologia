# Manrope variável — subconjunto latino

Arquivo: `manrope-latin-variable.woff2` (pesos de 200 a 800, estilo normal).
Fonte oficial do projeto Manrope, versão v20, distribuída por
`@fontsource-variable/manrope@5.3.0`, cuja origem é `google/fonts`.

O pacote foi obtido pelo registro npm por HTTPS, e sua integridade SHA-512
foi conferida contra os metadados do registro antes da cópia.

A licença OFL-1.1 está em `OFL.txt` e também é copiada para `out/fonts/OFL.txt`
durante o build. O carregamento usa `next/font/local`, sem acesso externo no
build ou no navegador. O arquivo é o mesmo utilizado na revisão visual da Manrope.
